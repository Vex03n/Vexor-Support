Secure Boot طريقة ايقاف

الشكل يختلف من جهاز الى جهاز تابع خطواته والخيارات

الطريقة

اضغط Start اكتب cmd

اضغط تشغيل كمسؤول+ حط هذا الأمر:

shutdown /r /o /f /t 0

تابع المقطع من دقيقه : 1.10

اذا شكل الي عندك غير الي بالمقطع ركز ب كلامه والخيارات الي يدخلها نفس الخيارات بس الشكل غير
